A fast drop-in for make.fun's csv-reader 1.0.0: it reads broken CSV files — unbalanced quotes, embedded newlines, stray CRs, ragged rows — and answers exactly as the reference does, at about twice the reference's speed. Clean lines go through one native split; every other record is read field by field with indexOf jumps over cached line extents, and only the rare broken paths (junk after a closing quote, a quote that never closes, a stray CR inside a field) take the slow road.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```

`main.ts` reads every case from `$MAKEFUN_INPUT_DIR/cases.json`, answers each with `run()` from `solve.js`, and writes `$MAKEFUN_OUTPUT_DIR/answers.json`.
